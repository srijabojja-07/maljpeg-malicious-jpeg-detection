# Dataset Information

## 1. Oxford5k Dataset

Purpose:
Used as the benign image dataset.

Description:
Oxford5k is a collection of real-world photographs commonly used for image retrieval research. In this project, the images are treated as legitimate JPEG files representing non-malicious content.

Role in Project:

* Benign JPEG samples
* Baseline image characteristics
* Normal JPEG marker analysis

## 2. Malware Benign Image Sample Dataset

Purpose:
Used as the malicious image dataset.

Description:
This dataset contains malicious and benign image samples used for cybersecurity research. Malicious images contain manipulated JPEG structures and suspicious marker patterns that can indicate hidden malicious payloads.

Role in Project:

* Malicious JPEG samples
* Malware detection training
* Feature extraction and comparison

## Dataset Usage

Training Set:
Used for machine learning model training.

Testing Set:
Used for evaluating model performance.

Validation:
Performance measured using accuracy, precision, recall, F1-score, and ROC-AUC metrics.

## Note

The datasets are used strictly for educational and cybersecurity research purposes.
